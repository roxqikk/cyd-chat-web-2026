# CYD Chat 2.0 — русский веб-клиент

Адаптивный интерфейс для CYD Chat и ESP32-2432S028. Полностью русский интерфейс, кириллица, подключение к комнате по коду и паролю, сообщения через защищённый WebSocket (WSS).

## GitHub Pages

Откройте **Settings → Pages → Deploy from a branch → main → /(root)**. GitHub Pages размещает только статический сайт.

## Необходимый сервер

Клиент требует отдельно развёрнутый сервер по HTTPS с WebSocket-маршрутом `/ws` (протокол `wss://`). Формат JSON:
- После подключения клиент отправляет `{"type":"join","room":"room2026","password":"...","nick":"Гость"}`.
- Сервер отвечает `{"type":"joined"}` **только после успешной проверки** кода и пароля.
- Отправка сообщения: `{"type":"message","text":"Привет!"}`.
- Получение: `{"type":"message","nick":"Друг","text":"Привет!"}`.
- Ошибка: `{"type":"error","message":"Доступ запрещён"}`.

**Без работающего сервера чат не сможет обмениваться сообщениями.** Сервер должен проверять пароль и членство в комнате при каждом действии, ограничивать частоту и размер сообщений, хранить только стойкие хеши паролей (Argon2id), не писать пароли в логи, ограничивать CORS/Origin для WebSocket и предотвращать подбор паролей. Не отправляйте секреты в GitHub. Для настоящей конфиденциальности потребуется отдельно спроектированное сквозное шифрование.

Кириллица на сайте поддерживается системными шрифтами. **На CYD с LVGL** нужно отдельно подключить шрифт с русскими глифами и русскую раскладку клавиатуры; обновление сайта **не прошивает ESP32**.
