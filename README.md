# CYD Chat 2.0 — Website

Статический адаптивный HTML-сайт проекта CYD Chat 2.0.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий, например `cyd-chat-website`.
2. Загрузите `index.html` в корень репозитория.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку **main**, каталог **/(root)** и сохраните.
5. Когда GitHub Pages опубликует сайт, ссылка появится в разделе Pages.

Сайт не является сервером чата и не содержит секретов или Wi-Fi-паролей.
